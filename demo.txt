Register a new app:

curl -X POST http://localhost:3000/api/v1/registerApp \
-H "Content-Type: application/json" \
-d '{
  "signedMessage": "dummy_signed_message",
  "name": "Demo App",
  "description": "This is a demonstration application",
  "contactEmail": "demo@example.com"
}'

Get the app metadata (replace APP_ID with the ID received from step 1):

curl http://localhost:3000/api/v1/appMetadata/APP_ID

Update the app (replace APP_ID with the ID from step 1):

curl -X PUT http://localhost:3000/api/v1/updateApp \
-H "Content-Type: application/json" \
-d '{
  "signedMessage": "dummy_signed_message",
  "name": "Updated Demo App",
  "description": "This is an updated demonstration application",
  "contactEmail": "updated_demo@example.com"
}'

Create a new role for the app (replace APP_ID with the ID from step 1):

curl -X POST http://localhost:3000/api/v1/createRole \
-H "Content-Type: application/json" \
-d '{
  "signedMessage": "dummy_signed_message",
  "name": "Demo Role",
  "description": "This is a demonstration role",
  "toolPolicy": [
    {
      "toolIpfsCid": "ipfs://demo_tool_cid",
      "policyVarsSchema": [
        {
          "paramName": "demoParam",
          "valueType": "string",
          "defaultValue": "demoValue"
        }
      ]
    }
  ]
}'

Get the role (replace APP_ID and ROLE_ID with the IDs from steps 1 and 4):

curl http://localhost:3000/api/v1/role/APP_ID/ROLE_ID

Update the role (replace APP_ID and ROLE_ID with the IDs from steps 1 and 4):

curl -X PUT http://localhost:3000/api/v1/updateRole \
-H "Content-Type: application/json" \
-d '{
  "signedMessage": "dummy_signed_message",
  "roleId": "ROLE_ID",
  "name": "Updated Demo Role",
  "description": "This is an updated demonstration role",
  "toolPolicy": [
    {
      "toolIpfsCid": "ipfs://updated_demo_tool_cid",
      "policyVarsSchema": [
        {
          "paramName": "updatedDemoParam",
          "valueType": "number",
          "defaultValue": 42
        }
      ]
    }
  ]
}'

Get the updated role again to confirm changes (replace APP_ID and ROLE_ID with the IDs from steps 1 and 4):

bashCopycurl http://localhost:3000/api/v1/role/APP_ID/ROLE_ID
